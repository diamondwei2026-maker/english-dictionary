# PRD 增量更新模板

> 当 Figma 原型新增功能时，按此模板逐章检查并更新 PRD。
> 每个需要更新的章节都列出了具体检查项和修改规则。

---

## 更新流程

```
1. 从阶段 1 差异清单出发 → 逐项判定影响哪些 PRD 章节
2. 按本模板的章节顺序逐章检查
3. 对每个需要更新的章节执行 Edit
4. 全部更新后输出变更摘要，等待用户确认
```

## 章节检查清单

### §2.4 核心价值主张

- [ ] 新功能是否涉及新的价值领域？
  - 是 → 在价值主张列表中新增一行

### §4.1 核心用户旅程

**检查项**：新功能是否引入了新的用户操作流程？

- [ ] 每条新旅程包含：
  - **用户目标**：一句话
  - **前置条件**：登录态、数据存在等
  - **操作步骤**：编号列表，每步对齐 UI 交互
  - **预期结果**：操作完成后的状态
  - **异常分支**：失败/空数据/权限不足时的行为

**示例新增旅程**（收藏功能）：

```markdown
#### 旅程 N：收藏单词

- **用户目标**：收藏需要复习的单词，在个人中心集中查看
- **前置条件**：用户已登录
- **操作步骤**：
  1. 在单词详情页点击收藏按钮（Bookmark 图标）
  2. 按钮变为蓝色填充态，表示已收藏
  3. 进入个人中心 → 点击「我的收藏」入口
  4. 查看已收藏单词列表（单词名 + 音标 + 核心义摘要）
  5. 可点击取消收藏或进入单词详情
- **预期结果**：用户可在个人中心随时访问已收藏的单词
- **异常分支**：未登录 → 点击收藏按钮跳转登录页
```

**修改已有旅程**：如果新功能改变了已有旅程的步骤（如单词详情页新增社区笔记交互），修改对应步骤而非整条重写。

### §6.1 核心业务规则

**新增规则编号规则**：接续当前最大编号 BR-XX → BR-XX+1。

**示例**：

```markdown
| BR-13 | 收藏切换 | 用户点击收藏按钮 | 已收藏→取消收藏；未收藏→添加收藏。未登录→跳转登录页。后端幂等设计 |
| BR-14 | 社区笔记可见性 | 任何人进入单词详情页 | 所有用户的笔记均可查看，按点赞数降序排列 |
| BR-15 | 点赞切换 | 已登录用户点击 Heart | 已赞→取消赞；未赞→添加赞。未登录→跳转登录页。前端乐观更新 |
```

### §7.1 验收标准

**新增编号规则**：接续当前最大编号 AC-XX → AC-XX+1。

**示例**：

```markdown
| AC-19 | When 已登录用户在单词详情页点击收藏按钮, Given 单词未被收藏, Then 按钮变为蓝色填充态 |
| AC-20 | When 已登录用户进入个人中心点击「我的收藏」, Given 已收藏 2 个单词, Then 收藏页面显示 2 张单词卡片，计数正确 |
| AC-21 | When 未登录用户进入单词详情页, Given 该单词有 3 条他人笔记, Then 笔记区显示 3 条笔记，按点赞数降序 |
| AC-22 | When 已登录用户对一条笔记点赞, Given 该笔记未被当前用户点赞, Then Heart 变为蓝色填充，点赞数 +1 |
| AC-23 | When 已登录用户在「我的笔记」Tab 下新增笔记, Given 保存成功, Then 笔记同时出现在「我的笔记」和「所有笔记」Tab |
| AC-24 | When 未登录用户点击 Heart 按钮, Given 无登录态, Then 跳转登录页 |
```
