# Task 3.3: 前端数据层集成

| 属性 | 值 |
|------|-----|
| ID | 3.3 |
| 状态 | done |
| 优先级 | P0 |
| 依赖 | Task 3.2 |
| 阶段 | 阶段3: 词库与单词 CRUD |
| 预估工时 | 3-4 小时 |

## 描述

将前端所有页面中的 mock 数据调用替换为真实后端 API 调用。包括首页今日一词、单词搜索、单词详情、词库列表、词库下单词列表、管理后台词库/单词 CRUD 操作。确保数据流完整可用。

## 验收标准

- [ ] 首页「今日一词」从 API 获取（可先使用随机单词接口，推荐算法在 Task 5.2 实现）
- [ ] 单词搜索页调用 `GET /api/words?q=keyword` 真实搜索
- [ ] 单词详情页调用 `GET /api/words/:id` 获取完整数据（物理意象、引申义链、搭配）
- [ ] 词库列表页调用 `GET /api/wordbanks` 展示公开词库
- [ ] 词库下单词列表页调用 `GET /api/wordbanks/:id/words`
- [ ] 管理后台：词库管理页 CRUD 操作调用真实 API
- [ ] 管理后台：单词管理页 CRUD 操作调用真实 API
- [ ] API 调用增加 loading/error 状态处理
- [ ] 前端不再依赖 mock 数据文件（但保留以备测试参考）

## 子任务

### SUB-3.3.1: 用户端页面 API 集成
- **描述**: 首页、搜索、单词详情、词库列表等用户端页面对接 API
- **验收标准**:
  - [ ] 首页今日一词正常展示
  - [ ] 搜索功能可用
  - [ ] 单词详情完整展示
  - [ ] 词库列表和词库下单词正常展示

### SUB-3.3.2: 管理后台 API 集成
- **描述**: 管理后台所有 CRUD 操作对接 API
- **验收标准**:
  - [ ] 词库列表、新增、编辑、删除可用
  - [ ] 单词列表（支持按词库筛选）、新增、编辑、删除可用
  - [ ] 操作反馈（成功提示/失败提示）正常

### SUB-3.3.3: 错误与边界处理
- **描述**: 完善 API 集成的加载态、空态、错误态
- **验收标准**:
  - [ ] 数据加载中显示 loading 状态
  - [ ] 列表为空时显示空状态提示
  - [ ] 网络错误时显示错误提示 + 重试按钮
  - [ ] 404 单词/词库不存在时友好提示
