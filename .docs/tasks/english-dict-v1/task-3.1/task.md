## 描述

实现词库（WordBank）的完整 CRUD API。词库是单词的容器（如"基础高频词汇"、"商务英语"），支持列表查询、新增、编辑、删除。管理员可管理所有词库，普通用户可查看公开词库。

## 验收标准

- [ ] `GET /api/wordbanks` — 词库列表，支持分页（page/pageSize），公开词库无需登录
- [ ] `GET /api/wordbanks/:id` — 词库详情（含单词数量统计）
- [ ] `POST /api/wordbanks` — 新增词库（需管理员权限），接收 name、slug、description、cover_image
- [ ] `PUT /api/wordbanks/:id` — 编辑词库（需管理员权限）
- [ ] `DELETE /api/wordbanks/:id` — 删除词库（需管理员权限），级联处理关联单词
- [ ] 公开/私有词库区分（is_public 字段），普通用户只看到公开词库
- [ ] slug 唯一性校验
- [ ] 分页查询返回 total、page、pageSize

## 子任务

### SUB-3.1.1: 词库列表与详情
- **描述**: 实现词库查询接口（列表 + 详情）
- **验收标准**:
  - [ ] 列表接口返回分页数据
  - [ ] 详情接口包含单词数量统计
  - [ ] 普通用户仅看到公开词库

### SUB-3.1.2: 词库新增与编辑
- **描述**: 实现词库写操作接口（新增 + 编辑）
- **验收标准**:
  - [ ] 新增接口校验必填字段（name, slug）
  - [ ] slug 唯一性校验，重复返回 409
  - [ ] 编辑接口仅更新传入字段（部分更新）

### SUB-3.1.3: 词库删除
- **描述**: 实现词库删除，处理关联数据
- **验收标准**:
  - [ ] 删除词库同时删除关联单词（或设置为未分类）
  - [ ] 仅管理员可删除
