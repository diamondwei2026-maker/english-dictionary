# Task 1.3: Seed 数据脚本与连接池配置

| 属性 | 值 |
|------|-----|
| ID | 1.3 |
| 状态 | pending |
| 优先级 | P0 |
| 依赖 | Task 1.2 |
| 阶段 | 阶段1: 数据层 |
| 预估工时 | 2-3 小时 |

## 描述

编写 Seed 脚本，将前端现有 mock 数据（`src/data/mockData.ts` 或类似文件）迁移到数据库中。同时配置数据库连接池参数，确保生产环境的稳定连接管理。

## 验收标准

- [ ] Seed 脚本可从 mock 数据文件读取词库和单词数据并写入数据库
- [ ] `npm run db:seed` 命令可一键导入所有种子数据
- [ ] Seed 脚本可重复执行而不产生重复数据（upsert / 先清空再插入）
- [ ] 连接池配置合理：最大连接数、空闲超时、连接超时等参数
- [ ] 数据库连接模块提供单例或依赖注入方式给服务层使用
- [ ] 环境变量区分开发/生产数据库配置

## 子任务

### SUB-1.3.1: 定位并分析前端 Mock 数据
- **描述**: 在 `src/` 目录中找到所有 mock 数据文件，分析数据结构和字段映射关系
- **验收标准**:
  - [ ] 所有 mock 数据源文件已识别
  - [ ] 字段映射关系文档化（mock 字段 → DB 字段）

### SUB-1.3.2: 编写 Seed 脚本
- **描述**: 编写种子数据导入脚本，支持幂等执行
- **验收标准**:
  - [ ] 词库 mock 数据正确导入
  - [ ] 单词、引申义、搭配 mock 数据正确导入（含关联关系）
  - [ ] 创建默认管理员用户

### SUB-1.3.3: 数据库连接池配置
- **描述**: 配置连接池参数，编写数据库连接管理模块
- **验收标准**:
  - [ ] 连接池参数可通过环境变量配置
  - [ ] 连接模块提供 `getDB()` 或等效接口
