# Task 4.3: 前端 AI 功能集成

| 属性 | 值 |
|------|-----|
| ID | 4.3 |
| 状态 | pending |
| 优先级 | P1 |
| 依赖 | Task 4.1 |
| 阶段 | 阶段4: AI 词条生成 |
| 预估工时 | 2-3 小时 |

## 描述

将前端管理后台的 AI 生成按钮从 mock setTimeout 替换为真实 API 调用。用户点击"AI 生成"按钮后，调用后端 AI 生成接口，等待结果并自动填充到表单中。

如果 Task 4.2 (SSE) 已完成，优先使用流式接口展示生成进度；否则使用非流式接口配合 loading 状态。

## 验收标准

- [ ] 管理后台单词编辑页的"AI 生成"按钮调用 `POST /api/words/generate`
- [ ] AI 生成过程中展示 loading 状态（如果启用了 SSE，展示逐字进度）
- [ ] 生成完成后自动回填表单：物理意象、核心义、引申义链、搭配
- [ ] 生成失败时展示友好错误提示，支持重试
- [ ] 对于已有 AI 生成内容的单词，提示"已生成，可强制重新生成"
- [ ] 移除前端 setTimeout mock AI 生成逻辑

## 子任务

### SUB-4.3.1: AI 生成按钮对接
- **描述**: 修改管理后台"AI 生成"按钮逻辑，调用真实 API
- **验收标准**:
  - [ ] 点击触发 API 请求
  - [ ] 生成中展示 loading
  - [ ] 成功自动回填表单

### SUB-4.3.2: 生成结果处理
- **描述**: 将 AI 返回的结构化数据映射到表单字段
- **验收标准**:
  - [ ] 物理意象、核心义正确填充
  - [ ] 引申义链（多条）正确填充
  - [ ] 搭配列表正确填充
