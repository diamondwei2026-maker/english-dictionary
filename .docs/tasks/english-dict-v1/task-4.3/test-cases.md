# 测试用例 — Task 4.3: 前端 AI 功能集成

## TC-001: AI 生成按钮触发 API 请求 — 正常流程
- **类型**: 功能测试
- **关联验收标准**: AC-1（管理后台单词编辑页"AI 生成"按钮调用 POST /api/words/generate）
- **前置条件**:
  - 管理员已登录，token 有效
  - 进入单词编辑页（新增或编辑模式）
  - 已选定所属词库
  - 输入有效英文单词（如 "flow"）
- **输入**:
  - 单词输入框：`"flow"`
  - 词库选择：任意有效 wordbankId（如 `"60f7c1a2b3c4d5e6f7a8b9c0"`）
- **执行步骤**:
  1. 在单词输入框中输入 "flow"
  2. 点击「AI 自动生成词条」按钮
  3. 观察按钮状态变化
  4. 等待请求完成
- **预期输出**:
  - 实际发出 `POST /api/v1/words/generate` 请求，请求体 `{ wordName: "flow", wordbankId: "..." }`
  - HTTP 状态码：200（重新生成）或 201（首次生成）
  - 响应体为完整的 Word 对象（含 coreMeaning、extendedMeanings、collocations 等）
  - 按钮恢复为非 loading 状态
- **清理**: 无（不实际写入数据库的测试环境）

## TC-002: AI 生成过程中展示 loading 状态
- **类型**: 功能测试
- **关联验收标准**: AC-2（AI 生成过程中展示 loading 状态）
- **前置条件**:
  - 管理员已登录
  - 进入单词新增页面，输入有效单词
- **输入**:
  - 单词：`"break"`
- **执行步骤**:
  1. 输入单词 "break"
  2. 点击「AI 自动生成词条」按钮
  3. 在请求 pending 期间观察 UI
  4. 等待请求返回
- **预期输出**:
  - 按钮文案变为「⏳ 正在生成...」
  - 按钮背景色变为 `#93C5FD`（disabled 风格）
  - 按钮不可再次点击（防止重复请求）
  - 请求完成后按钮恢复
- **清理**: 无

## TC-003: 生成完成后自动回填表单全部字段
- **类型**: 功能测试
- **关联验收标准**: AC-3（生成完成后自动回填表单：物理意象、核心义、引申义链、搭配）
- **前置条件**:
  - 管理员已登录，进入新增单词页面
  - 后端 AI 服务正常
- **输入**:
  - 单词：`"grasp"`
  - 词库：已选择
- **执行步骤**:
  1. 输入 "grasp"，选择词库
  2. 点击「AI 自动生成词条」
  3. 等待 API 返回
  4. 检查各表单字段
- **预期输出**:
  - **音标**字段填充后端返回的 phonetic 值
  - **核心义描述**字段填充 coreMeaning
  - **核心义图类型**字段填充 physicalImageType（须为有效枚举值："flow"/"grasp"/"break"/"bear"/"drive"/"light"/"leverage"/"yield" 之一）
  - **意象描述**字段填充 physicalImageDescription
  - **核心义例句**填充 coreExampleEn（前端字段 `coreExampleSentence`）
  - **例句中文翻译**填充 coreExampleZh（前端字段 `coreExampleTranslation`）
  - **引申义列表**：每个引申义包含逻辑演化描述、含义、词性、例句、例句翻译
  - **常见搭配**字段填充 collocations 数组（用分隔符连接显示）
  - 按钮变为「✓ 已生成，可继续编辑」（绿色 `#059669` 背景）
- **清理**: 无

## TC-004: 生成失败 — 网络错误时展示友好提示
- **类型**: 异常测试
- **关联验收标准**: AC-4（生成失败时展示友好错误提示，支持重试）
- **前置条件**:
  - 管理员已登录，进入新增页面
  - 模拟网络断开或超时
- **输入**:
  - 单词：`"light"`
- **执行步骤**:
  1. 断网或 Mock 网络超时
  2. 输入 "light" 并点击「AI 自动生成词条」
  3. 等待请求失败
- **预期输出**:
  - 按钮从 loading 状态恢复为可点击
  - 使用 `Taro.showToast` 展示错误提示，如"网络连接失败，请检查网络"
  - 错误提示为友好中文文案，不暴露技术细节
  - 表单数据不丢失，用户可再次点击按钮重试
- **清理**: 恢复网络

## TC-005: 生成失败 — 服务端错误 + 重试成功
- **类型**: 异常测试 + 功能测试
- **关联验收标准**: AC-4（生成失败时展示友好错误提示，支持重试）
- **前置条件**:
  - 管理员已登录
- **输入**:
  - 单词：`"yield"`
- **执行步骤**:
  1. Mock 首次 API 返回 500
  2. 点击「AI 自动生成词条」
  3. 观察错误提示
  4. 修复 Mock 为正常返回
  5. 再次点击按钮
- **预期输出**:
  - 首次失败：Toast 展示"服务器错误，请稍后再试"
  - 按钮从 loading 恢复为可点击
  - 表单数据保留
  - 第二次点击成功，自动回填表单
  - 按钮变为「✓ 已生成，可继续编辑」
- **清理**: 恢复 Mock

## TC-006: 已有 AI 内容的单词 — 强制重新生成
- **类型**: 功能测试
- **关联验收标准**: AC-5（对于已有 AI 生成内容的单词，提示"已生成，可强制重新生成"）
- **前置条件**:
  - 管理员已登录
  - 编辑一个已有 AI 生成内容的单词（coreMeaning、extendedMeanings 等字段非空）
- **输入**:
  - 编辑模式下打开已有单词
- **执行步骤**:
  1. 打开一个已存在的单词编辑页
  2. 观察 AI 生成区域
  3. 修改单词拼写（如添加一个字母）
  4. 观察按钮状态变化
  5. 点击按钮触发重新生成
- **预期输出**:
  - 初始状态：按钮文案为「✓ 已生成，可继续编辑」（绿色）
  - 修改单词后：按钮文案变回「AI 自动生成词条」（蓝色），aiDone 状态重置
  - 点击后正常发起请求，可带 `?force=true` 查询参数
  - 生成完成后表单更新为新内容
- **清理**: 无

## TC-009: 后端响应数据字段缺失
- **类型**: 异常测试
- **关联验收标准**: AC-3（延伸）
- **前置条件**:
  - 管理员已登录
  - Mock 后端返回不完整数据（缺失 extendedMeanings 或 collocations 字段）
- **输入**:
  - 单词：`"test"`
- **执行步骤**:
  1. Mock API 返回 `{ word: "test", coreMeaning: "..." }`，缺失 extededMeanings 和 collocations
  2. 点击 AI 生成
- **预期输出**:
  - 表单不崩溃，现有字段正常填充
  - 缺失字段保持为空或默认值，不影响页面渲染
  - extendedMeanings 为空时不渲染空的引申义卡片
  - collocations 为空时搭配输入框为空
- **清理**: 恢复 Mock

- **类型**: 功能测试

- **预期输出**:
