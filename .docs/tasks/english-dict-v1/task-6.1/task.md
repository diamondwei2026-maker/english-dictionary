# Task 6.1: 缓存与搜索优化

| 属性 | 值 |
|------|-----|
| ID | 6.1 |
| 状态 | pending |
| 优先级 | P2 |
| 依赖 | Task 5.2 |
| 阶段 | 阶段6: 优化与上线 |
| 预估工时 | 2-3 小时 |

## 描述

对 API 响应进行缓存优化（重点是高频读取的今日一词、词库列表、单词详情）和搜索性能优化（数据库索引、全文搜索或 LIKE 性能调优）。

## 验收标准

- [ ] 高频读接口（今日一词、词库列表、单词详情）加入缓存层
- [ ] 缓存策略：内存缓存或 Redis（可选），合理设置 TTL
- [ ] 数据变更（词库/单词修改）时主动失效对应缓存
- [ ] 单词搜索确认数据库索引生效（EXPLAIN 分析）
- [ ] 搜索结果按相关度排序（前缀匹配优先于中间匹配）
- [ ] 搜索支持分页，避免全表扫描
- [ ] 缓存可配置（是否启用、TTL 时长）

## 子任务

### SUB-6.1.1: API 响应缓存
- **描述**: 为高频读接口增加缓存层
- **验收标准**:
  - [ ] 今日一词缓存（按天）
  - [ ] 词库列表缓存（TTL 5 分钟）
  - [ ] 单词详情缓存（TTL 10 分钟）
  - [ ] 数据变更时缓存失效

### SUB-6.1.2: 搜索性能优化
- **描述**: 优化单词搜索的数据库查询性能
- **验收标准**:
  - [ ] words.name 建立索引
  - [ ] EXPLAIN 验证索引使用
  - [ ] 搜索结果排序优化
