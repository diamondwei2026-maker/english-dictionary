## 描述

实现用户个人学习记录和单词收藏功能。学习记录追踪用户查看过哪些单词、学习次数；收藏功能让用户创建个人生词本，方便复习。

## 验收标准

- [ ] `POST /api/words/:id/learn` — 记录用户学习该单词（需登录），累计学习次数
- [ ] `GET /api/user/learning-records` — 获取用户学习记录列表，按最近学习时间排序
- [ ] `GET /api/user/stats` — 用户学习统计（已学单词数、学习天数、今日学习数）
- [ ] `POST /api/words/:id/favorite` — 收藏单词（需登录）
- [ ] `DELETE /api/words/:id/favorite` — 取消收藏
- [ ] `GET /api/user/favorites` — 获取用户收藏单词列表
- [ ] `GET /api/words/:id` 响应中增加 `is_favorited`、`learn_count` 字段（当前用户相关）
- [ ] 前端单词详情页展示收藏按钮（调用真实 API）
- [ ] 前端用户中心展示学习统计和收藏列表

## 子任务

### SUB-5.1.1: 学习记录 API
- **描述**: 实现学习记录相关的后端 API
- **验收标准**:
  - [ ] 学习记录写接口（记录/更新学习时间和次数）
  - [ ] 学习统计接口（已学单词、天数、今日学习数）
  - [ ] 学习记录列表接口

### SUB-5.1.2: 收藏功能 API
- **描述**: 实现单词收藏相关的后端 API
- **验收标准**:
  - [ ] 收藏/取消收藏接口
  - [ ] 收藏列表接口（分页）
  - [ ] 单词详情接口返回 is_favorited 状态

### SUB-5.1.3: 前端集成
- **描述**: 前端对接学习记录和收藏 API
- **验收标准**:
  - [ ] 单词详情页收藏按钮可用
  - [ ] 用户中心展示学习统计和收藏列表
  - [ ] 浏览单词自动记录学习
