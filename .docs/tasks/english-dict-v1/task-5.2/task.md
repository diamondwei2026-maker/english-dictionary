# Task 5.2: 今日一词推荐与管理后台概览

| 属性 | 值 |
|------|-----|
| ID | 5.2 |
| 状态 | done |
| 优先级 | P1 |
| 依赖 | Task 5.1 |
| 阶段 | 阶段5: 增强功能 |
| 预估工时 | 3-4 小时 |

## 描述

实现今日一词的智能推荐算法（替换前端随机取模），以及管理后台首页的数据概览仪表盘（Dashboard），展示词库/单词/用户的实时统计数据。

## 验收标准

- [ ] `GET /api/daily-word` — 返回今日推荐单词（一天内同一单词不变）
- [ ] 推荐策略：优先从未学单词中选、考虑单词重要度（高频词优先）、记录已推荐历史避免短期内重复
- [ ] 支持管理员手动设置今日一词（`POST /api/daily-word/pin`）
- [ ] `GET /api/admin/dashboard` — 管理后台数据概览（需管理员）
  - 词库总数
  - 单词总数
  - 注册用户总数
  - 最近 7 天新增单词趋势
  - 最近 7 天新增用户趋势
- [ ] 前端首页今日一词调用 `GET /api/daily-word`
- [ ] 前端管理后台概览页调用 `GET /api/admin/dashboard`

## 子任务

### SUB-5.2.1: 今日一词推荐服务
- **描述**: 实现每日一词推荐算法和 API
- **验收标准**:
  - [ ] 每日一词按天缓存（同一天返回同一单词）
  - [ ] 推荐逻辑合理（考虑用户已学/未学）
  - [ ] 支持管理员置顶指定单词

### SUB-5.2.2: 管理后台数据概览
- **描述**: 实现 Dashboard 统计 API
- **验收标准**:
  - [ ] 词库/单词/用户总数统计
  - [ ] 近 7 天新增趋势数据
  - [ ] 仅管理员可访问

### SUB-5.2.3: 前端集成
- **描述**: 首页和管理后台对接新 API
- **验收标准**:
  - [ ] 首页今日一词从 API 获取
  - [ ] 管理后台首页展示数据概览
