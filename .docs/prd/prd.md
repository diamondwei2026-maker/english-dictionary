## 2. 产品概述与背景

### 2.1 产品定位

面向中文母语者的认知语言学英语词典 APP。以**物理意象（Physical Image）**为切入点，帮助用户从最原初的物理感知理解英语词汇，再沿着逻辑演化路径掌握引申义，而非死记硬背中文翻译。

### 2.2 业务背景

传统英汉词典的问题是：用户看到中文翻译（如 `grasp = 理解`），却不知道这个词和"抓住"之间的关联，导致记忆碎片化、无法灵活运用。本产品引入认知语言学方法——每个单词关联一张物理意象 SVG 图示（如"液体沿阻力最小路径流动"→ flow），展示词义从物理感知到抽象引申的完整演化链。

### 2.3 产品目标

- 建立以物理意象为核心的词典产品心智，差异化传统英汉词典
- 支持按词库维度组织词汇（基础高频 / 商务 / 学术 / 动词专项等）
- 提供管理后台，使内容运营人员可自助维护词库和词条
- 为后续引入 AI 自动生成词条铺好产品框架（管理后台已预留 AI 生成能力）
- 支持用户在单词详情页添加个人笔记，强化学习过程中的主动输出；同时可浏览其他用户的公开笔记和点赞互动
- 提供短句中译英翻译训练，在句子中建立从中文意图到英语表达的直接反应，把"看懂词义"闭环到"能用词造句"

### 2.4 核心价值主张

**不是查翻译，而是建立语感锚点**——每个单词回到最原始的物理意象，像母语者一样从感知出发理解词汇。

## 3. 目标用户画像

### 3.1 用户角色概览

| 角色 | 描述 | 核心诉求 |
|------|------|---------|
| 普通用户 | 中文母语英语学习者，有一定基础（高中以上），希望突破"中式英语"思维 | 查词时看到词义来源，理解引申逻辑，积累搭配；记录个人笔记巩固记忆 |
| 管理员 | 词典内容运营人员，负责维护词库和词条内容 | 高效增删改查词库/词条，支持 AI 辅助生成内容 |

### 3.2 各角色详细画像

**普通用户**

- 使用场景：利用碎片时间每日学 3-5 个单词；遇到生词随时搜索；按词库系统学习某一类词汇；在单词详情页记录个人笔记
- 典型行为：打开 APP 浏览「今日一词」→ 查看词义演化链条 → 学习引申义 → 记忆搭配 → 添加个人笔记 → 收藏单词 → 浏览社区笔记并点赞
- 痛点：现有词典只给中文翻译，缺乏系统性词义理解，记了就忘
- 期望：看到一个词的"为什么"，理解词义演化的逻辑链；用笔记功能记录个人理解和记忆线索

**管理员**

- 使用场景：日常维护词库内容，新增/编辑/删除词库和词条；使用 AI 辅助生成词条初稿后人工润色
- 典型行为：在后台概览查看数据总量 → 进入词库/单词管理 → 新增或编辑条目 → AI 填充基础内容 → 人工修正后发布
- 痛点：手工编排认知语言学词条工作量巨大，需要 AI 辅助提效
- 期望：AI 一键生成词条的物理意象、引申义链、例句和搭配

## 4. 用户故事与场景

### 4.1 核心用户旅程

#### 旅程 1：普通用户每日学词

- **用户目标**：今日花 5 分钟学习一个单词的完整认知
- **前置条件**：用户已登录
- **操作步骤**：
  1. 打开 APP，首页展示「今日一词」（蓝色渐变卡片，含物理意象描述）
  2. 点击进入单词详情页 → 看到物理意象 SVG 图示
  3. 阅读「核心义」+ 例句（中英对照）
  4. 逐条下滑阅读「引申义演化」：逻辑演化描述 → 引申义 → 词性 → 例句
  5. 底部查看「常见搭配」，建立语感
  6. 在「我的笔记」区域添加个人理解，巩固记忆
- **预期结果**：用户完成了对一个单词从物理感知到抽象引申的完整学习，并留下了个人笔记
- **异常分支**：单词不存在 → 提示"单词不存在"，引导返回首页

#### 旅程 2：搜索并学习特定单词

- **用户目标**：在阅读或工作中遇到一个生词，搜索并理解它
- **前置条件**：无
- **操作步骤**：
  1. 在首页搜索框输入英文单词
  2. 搜索结果实时过滤显示匹配的单词列表（按单词名/核心义匹配）
  3. 点击单词进入详情页，按旅程 1 流程学习
- **预期结果**：快速找到目标单词并完成学习
- **异常分支**：无匹配结果 → 提示"未找到相关单词"，引导去管理后台添加

#### 旅程 3：查看和回顾我的笔记

- **用户目标**：回顾以往学习时记录的笔记，按单词维度浏览
- **前置条件**：用户已登录
- **操作步骤**：
  1. 进入个人中心 → 点击「我的笔记」入口（显示笔记条数）
  2. 第一级：看到有笔记的单词列表，每个显示单词名 + 笔记条数
  3. 点击某个单词 → 进入第二级：该单词下所有笔记卡片（内容 + 日期 + 删除按钮）
  4. 可删除单条笔记；可从第二级点击「查看单词详情」跳转到单词详情页
- **预期结果**：用户可以方便地按单词维度回顾所有笔记
- **异常分支**：无笔记 → 显示空状态"还没有笔记"，引导去单词详情页添加

#### 旅程 4：忘记密码找回

- **用户目标**：忘记登录密码后通过手机号找回
- **前置条件**：用户已有注册账号
- **操作步骤**：
  1. 登录页点击「忘记密码？」链接
  2. Step 1 — 验证手机号：输入手机号（+86 前缀），点击「获取验证码」
  3. Step 2 — 输入验证码：收到 6 位验证码（演示环境任意 6 位），输入后点击「下一步」
  4. Step 3 — 设置新密码：输入新密码 + 确认密码（至少 6 位，两次一致）
  5. 提交后显示成功提示 → 自动跳回登录页
- **预期结果**：用户成功重置密码，可用新密码登录
- **异常分支**：
  - 手机号格式不合法 → 提示"请输入有效的手机号"
  - 验证码非 6 位 → 提示"请输入 6 位数字验证码"
  - 密码少于 6 位 → 提示"密码至少 6 位"
  - 两次密码不一致 → 提示"两次密码不一致"

#### 旅程 5：管理员维护词库

- **用户目标**：为 APP 新增一个词库并添加若干词条
- **前置条件**：管理员已登录
- **操作步骤**：
  1. 进入个人中心 → 点击「管理后台」→ 进入数据概览页
  2. 进入「词库管理」→ 点击新增 → 填写名称和描述 → 保存
  3. 进入「单词管理」→ 点击新增 → 输入单词名 → 点击「AI 自动生成词条」
  4. AI 填充音标、核心义、物理意象类型、例句、引申义链、搭配
  5. 管理员人工校验/修改各项内容 → 保存
- **预期结果**：新词库和词条成功创建，在前端搜索可查
- **异常分支**：AI 生成超时 → 显示加载动画后自动完成（模拟场景中延迟 1.8s）

#### 旅程 6：查看和管理收藏单词

- **用户目标**：查看已收藏的单词列表，取消不再需要的收藏
- **前置条件**：用户已登录
- **操作步骤**：
  1. 进入个人中心 → 点击「我的收藏」入口（显示收藏单词数）
  2. 进入收藏列表页：顶部 sticky header（返回 + "我的收藏"标题）
  3. 加载时显示"加载中..."
  4. 有收藏单词时：显示"共 N 个单词"标签 → 单词卡片列表（每张卡片含单词名 + 音标 + 核心义截断 + 取消收藏按钮）
  5. 点击单词卡片 → 跳转单词详情页
  6. 点击取消收藏按钮 → 该单词从列表中即时移除
  7. 若取消最后一项，显示空状态
- **预期结果**：用户可以方便地管理已收藏的单词
- **异常分支**：
  - 无收藏 → 显示空状态"还没有收藏单词"，引导去单词详情页添加
  - API 加载失败 → 提示"加载失败，请检查网络"

#### 旅程 7：短句中译英翻译训练

- **用户目标**：通过 10 道中译英短句练习，检验是否能用已学单词正确组织英语表达
- **前置条件**：无（训练页无需登录）
- **操作步骤**：
  1. 点击底部导航「训练」Tab 进入训练首页
  2. 训练首页展示两个选项卡片：「短句中译英」（可用）和「短句英译中」（禁用态 + "即将上线"标签）
  3. 点击「短句中译英」→ 进入答题界面，自动生成 10 道中译英短句题
  4. 逐题在 textarea 输入英文表达 → 点击「提交」→ 系统判断正确/错误
  5. 正确时显示绿色反馈（Check 图标 + 肯定分析 + 参考答案）
  6. 错误时显示红色反馈（X 图标 + 中文意象分析 + 缺失关键词提示 + 参考答案）
  7. 进度条随答题推进；10 题完成后查看结果页（正确数/正确率/逐题回顾）
  8. 可点击「再来一组」重新生成题目，或点击「返回」回到训练首页
- **预期结果**：用户完成一轮翻译训练，获得即时判分反馈和中文意象分析
- **异常分支**：
  - 空输入提交 → 直接判错，提示"你还没有输入答案"
  - 从单词详情页「专项练习」入口进入 → 题目围绕该单词生成，返回按钮回到单词详情页

### 5.2 各功能详细说明

#### F-01：首页搜索与词表

- **优先级**：P0
- **功能描述**：提供搜索框输入英文单词进行实时过滤；无搜索内容时展示全部词汇列表
- **前置条件**：无
- **主要流程**：
  1. 用户在搜索框输入文字
  2. 系统实时匹配单词名（大小写不敏感）和核心义描述
  3. 结果以列表展示：单词名 + 音标 + 核心义截断预览 + 所属词库标签
  4. 无匹配时显示空状态文案
- **异常处理**：搜索无结果 → 提示"未找到相关单词，可在管理后台添加新词汇"
- **关联功能**：F-03 单词详情页（点击搜索结果跳转）

#### F-02：今日一词

- **优先级**：P1
- **功能描述**：首页顶部以醒目蓝色渐变卡片每日推荐一个单词
- **前置条件**：无
- **主要流程**：
  1. 按当天日期取模 mockWords 数组，确定今日单词
  2. 卡片展示：标签"核心物理意象" + 单词名 + 音标 + 核心义描述
  3. 点击进入该单词详情页
- **异常处理**：无
- **关联功能**：F-03 单词详情页

#### F-03：单词详情页

- **优先级**：P0
- **功能描述**：展示一个单词的完整认知语言学信息，并集成个人笔记功能
- **前置条件**：从搜索/词表/今日一词/词库详情/笔记列表点击进入，携带 wordId
- **主要流程**：
  1. 顶部 sticky 栏：返回按钮 + 所属词库标签
  2. 单词大头：单词名（超大字号）+ 音标
  3. 物理意象区域：对应类型的 SVG 图示（如 flow→流速剖面图，grasp→多点包围施压图，break→应力断裂图 等 8 种）
  4. 核心义：核心义描述 + 中英对照例句（左侧蓝色边框高亮）
  5. 引申义演化：每个引申义独立卡片，包含 逻辑演化描述 → 箭头 → 引申义 + 词性标签 → 例句（左侧绿色边框高亮）
  6. 常见搭配：以 tag 形式横向排列
  7. **笔记区域**（含社区笔记 + 我的笔记两个 Tab）：
     - 社区笔记区：展示该单词所有用户公开笔记（按点赞数降序），每条含作者名 + 内容 + 日期 + 点赞数 + 点赞按钮
     - 我的笔记区（仅登录用户可见）：已保存的笔记卡片列表（内容 + 日期 + 删除按钮）
     - **持久化底部创作栏**（小红书风格）：固定在页面底部，未登录用户显示"登录后可点赞和写笔记"，已登录用户显示"写下你对这个词的理解…"；点击后弹出 slide-up 底部面板，内含 textarea + 「保存笔记」按钮（内容为空时禁用）
     - 保存后关闭面板并即时刷新笔记列表
- **异常处理**：wordId 无效 → 提示"单词不存在"，提供返回首页按钮
- **关联功能**：依赖 F-01、F-02、F-04；F-07 管理后台维护数据；F-09 笔记管理页

  4. 注册：输入用户名 + 手机号 + 密码 → 创建账号 → 自动登录
  5. 支持 Enter 键提交
  6. **忘记密码**（登录 Tab 可见）：
     - 点击密码字段下方「忘记密码？」链接 → 进入忘记密码流程（隐藏登录/注册 Tab 切换器）

     - Step 1 — 验证手机号：输入手机号（+86 前缀），点击「获取验证码」
     - Step 2 — 输入验证码：显示"验证码已发送至 +86 xxx"，输入 6 位数字验证码（演示环境任意 6 位均可通过），点击「下一步」

- **业务规则**：

- **优先级**：P1
- **功能描述**：提供中译英短句翻译练习（每轮 10 题），逐题判分并在答错时给出认知语言学意象分析；单词详情页提供针对该单词的专项练习入口。英译中入口预留（当前为禁用态 + "即将上线"标签）。
- **前置条件**：无（训练页无需登录，与社区笔记浏览逻辑一致）
- **主要流程**：

  **a) 训练首页**
  1. 底部导航新增「训练」Tab（Dumbbell 图标，位于词库和我的之间）
  2. 页面标题「训练」+ 副标题"从核心意象出发，在句子里建立英语的直接反应"
  3. 两张卡片按钮：
     - 「短句中译英」：可点击，图标 Languages，点击跳转答题页
     - 「短句英译中」：禁用态（opacity 0.55，cursor default），右上角挂「即将上线」胶囊标签（灰底灰字）

  **b) 答题页**
  1. 页面初始化：根据 direction 生成 10 道 QuizItem；有 wordId 时优先该单词题目，不足用同词库单词补齐，再无则从通用池随机
  2. 顶栏：返回按钮（回到训练首页，若带 wordId 则回到单词详情页）+ 进度"3 / 10" + 蓝色进度条
  3. 题卡：白底卡片，显示标签"翻译成英语"、题干大字、hint 提示标签
  4. 输入：多行 textarea（圆角 16px），聚焦时边框变主色 #2563EB
  5. 提交按钮：点击后调用 judgeAnswer 判分；已判分时按钮变"下一题"，最后一题变"查看结果"
  6. 判分反馈卡片（motion 淡入上移动画）：
     - 正确：绿底 #F0FDF4 + Check 图标 + 肯定分析 + 参考答案
     - 错误：红底 #FFF1F2 + X 图标 + 意象分析 + 缺失关键词提示 + 参考答案
  7. 完成页：正确数 / 10 + 正确率百分数 + 逐题回顾折叠列表（每题判分结果）+ 「再来一组」按钮（重新生成题目）+ 「返回」按钮

  **c) 判分规则（纯前端实现）**
  1. 输入归一化：小写、去首尾空白、折叠连续空格、去除句末标点
  2. 关键词命中率（支持简单词形变体 flow/flows/flowed/flowing）占 70 分
  3. 与参考答案的词序列 LCS 相似度占 30 分
  4. score ≥ 70 判对；空输入直接判错（score=0）

  **d) 单词详情页专项练习入口**
  1. 在核心义/引申义/搭配卡片与社区笔记区之间新增一张卡片
  2. Dumbbell 图标 + "用 {word} 造句练习" + 说明文案 + ChevronRight 箭头
  3. 点击进入答题页（direction='zh2en', wordId=当前单词ID）
  4. 返回按钮回到该单词详情页

- **异常处理**：
  - 生成题目不足 10 道 → 允许不足 10 题（当前题库可覆盖）
  - 空输入提交 → 直接判错，"你还没有输入答案"
- **关联功能**：F-03 单词详情页（专项练习入口）、F-08 底部导航（训练 Tab）
- **技术说明**：本轮采用本地模拟模式（mockQuizItems + 纯前端 quizEngine），后续接 Supabase/LLM 时替换 generateQuiz 和 judgeAnswer 两个函数即可

## 6. 业务规则与逻辑边界

### 6.1 核心业务规则

| 规则编号 | 规则描述 | 触发条件 | 规则逻辑 |
|---------|---------|---------|---------|
| BR-01 | 手机号校验 | 登录/注册/忘记密码提交 | 手机号去除空格后匹配正则 `^1[3-9]\d{9}$` |
| BR-02 | 角色跳转 | 登录成功后 | role=admin → 跳转管理后台；role=user → 跳转个人中心 |
| BR-03 | 今日一词算法 | 首页加载 | 取 `mockWords[Math.floor(Date.now() / 86400000) % mockWords.length]`，基于 UTC 天数取模 |
| BR-04 | 搜索匹配 | 用户输入搜索词 | 匹配 `word.word`（大小写不敏感）OR `word.coreMeaning` 包含搜索词 |
| BR-05 | AI 生成规则 | 管理后台点击 AI 生成 | 调用 DeepSeek API（V4 Pro + V4 Flash 双模型两阶段管线）生成词条 JSON（含 IPA 音标 + SVG 图示）；相同单词 24h 内走 LRU 缓存不重复调用；支持 SSE 流式响应 |
| BR-06 | 物理意象类型 | 编辑单词时选择 | 8 种：flow/grasp/break/bear/drive/light/leverage/yield，每种对应一个独有 SVG |
| BR-07 | 管理后台权限 | 访问管理后台 | 仅 role=admin 可见管理后台入口；后端 API 通过 adminMiddleware 鉴权，非 admin 返回 403 |
| BR-08 | 密码安全 | 登录/注册 | 密码经 bcrypt（10 rounds）加密存储；JWT Token 7d 有效期 |
| BR-09 | 笔记所有权 | 获取/创建/删除笔记 | 笔记仅所属用户可查看和操作；后端通过 authMiddleware 从 JWT 提取 userId，删除时校验所有权，非所有者返回 403 |
| BR-10 | 忘记密码流程 | 忘记密码提交流程 | 三步流程：验证手机号 → 输入 6 位验证码 → 设置新密码（≥6 位）；演示环境任意 6 位验证码均可通过 |
| BR-11 | 退出管理后台 | 管理员点击退出管理 | 调用 logout()，清除用户状态，跳转首页（非仅退出管理页面） |

| BR-16 | 训练题目生成 | 用户进入答题页 | 优先取 wordId 关联题目 → 同词库补齐 → 通用池随机；洗牌后取前 10 题 |

### 6.2 状态流转

#### 用户认证状态

```
未登录 → (登录成功) → 已登录(普通用户)
未登录 → (登录成功, role=admin) → 已登录(管理员)
已登录 → (退出登录) → 未登录
```

#### 视图路由状态（ViewState）

```
home ──→ wordDetail ──→ home
home ──→ libraries ──→ libraryWords ──→ wordDetail ──→ home
profile ──→ login ──→ profile
profile ──→ register ──→ profile
profile ──→ notes ──→ wordDetail ──→ home
profile ──→ favorites ──→ wordDetail ──→ home
profile ──→ admin (role=admin) ──→ adminWordEdit(预留) ──→ admin
admin ──→ home (退出管理 = logout)
training ──→ quiz ──→ training
training ──→ quiz ──→ wordDetail (来自专项练习入口)
```

### 6.3 边界条件与约束

- **数据持久化**：所有数据存储在 MongoDB Atlas，通过 REST API 读写，刷新/重启不丢失
- **设备适配**：最大宽度 430px，居中显示，移动端 H5 优先
- **管理后台与前端分离**：管理后台全屏覆盖，不显示底部导航，通过 JWT Token 角色鉴权
- **并发处理**：MongoDB 文档级原子操作；收藏/取消收藏幂等设计
- **笔记字数限制**：单条笔记内容最大 5000 字

## 8. 非功能需求

### 8.1 性能体验

- 搜索支持防抖（前端 300ms）+ 后端正则索引匹配，分页 20 条/页
- 物理意象 SVG 为内联 inline SVG，无额外网络请求
- AI 词条生成：首次调用 DeepSeek API（~3-5s），缓存命中 < 50ms
- SSE 流式响应：AI 生成结果逐字段推送，用户可实时看到内容
- 笔记加载与单词详情并行请求，不阻塞页面渲染

### 8.2 安全与合规

- 密码加密存储：bcrypt + salt（10 rounds）
- 认证：JWT Bearer Token（7d 有效期）
- API 鉴权：adminMiddleware 校验管理员角色；authMiddleware 校验登录态和笔记所有权
- 请求限流：登录 15min/10 次，AI 生成按用户 1min/10 次
- HTTP 安全头：Helmet（CSP、HSTS、X-Frame-Options 等）
- CORS：生产环境白名单限制 Vercel 域名
- 手机号格式校验：`^1[3-9]\d{9}$`（前后端双重校验）
- 笔记内容校验：最大 5000 字，前端禁用 + 后端拦截双重保护

### 8.3 兼容性与集成

- 目标平台：移动端浏览器（iOS Safari、Android Chrome），桌面端兼容但非主要场景
- 无外部系统集成需求（当前版本）
- 笔记功能完全自建，不依赖第三方笔记服务
